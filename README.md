# PokéDex

A dark, neon-green Pokédex built with React and Vite. Browse Pokémon and alternate forms, assemble a team, and battle trainers or wild encounters in the Arena.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Publish with GitHub Pages

The Vite base path is configured for the `PokeDex-01881250039` repository.

1. Push this project to a GitHub repository with that name.
2. Run `npm run deploy` to publish the build to the `gh-pages` branch.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch `gh-pages`, folder `/ (root)`.

GitHub Pages will show the published site URL in the Pages settings.
